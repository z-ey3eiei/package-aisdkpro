# ai-sdk.pro Streaming Chat

Use Node.js 22 or later. Run `npm install` and `npm run dev`.
Open http://localhost:3000 and enter your own OpenAI key in the app.

Before publishing, run `npm run build`. Commit the source and package-lock.json,
push to your GitHub repository, and deploy it as a Node.js application.
Use `npm ci` to install and `npm start` to serve the production build.
Set APP_ORIGIN to the deployed HTTPS origin in your hosting environment.
